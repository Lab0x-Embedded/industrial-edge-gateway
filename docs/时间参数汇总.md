# 时间参数汇总

> 本文汇总工业边缘网关项目中所有与时间相关的取值，并标注每项的「性质」（超时 / 轮询周期 / 占用时长 / 固定延时 / 时基 / 时序 / 次数）。
>
> 分类口径：
> - **超时**：到点就放弃 / 报错 / 判失败
> - **轮询周期**：任务循环的固定节拍，到点就跑下一轮
> - **占用时长**：一次操作实际占用 / 等待的时长上限
> - **固定延时**：纯 `vTaskDelay` / `HAL_Delay` 睡一会儿再继续
> - **时基**：计时基准
> - **时序**：硬件时序要求的建立 / 保持时间
> - **次数**：不是时间，是重试 / 失败次数上限

## 4. Modbus

### 主站侧（`User/modbus/modbus.c`）

| 项 | 值 | 备注 | 位置 |
|---|---|---|---|
| 等首字节超时 | 150 ms | 超时（死从机单台只等 150ms，原 800ms） | `:136` |
| 帧间静默 | 50 ms | 超时判定（3.5 字符） | `:208` |
| 绝对兜底 | 300 ms | 超时（从机发了半个帧卡住） | `:210` |
| 死从机跳过 | 连续 5 次失败跳过 | 次数（每 10 轮复活探测一次） | `:247` |
| 从机间隔 | 10 ms | 轮询周期（30ms→10ms，防总线冲突） | `:287` |
| `vTaskDelay(10)` | 10 ms | 固定延时（上报后） | `:318` |

> 优化说明：原单一 800ms 绝对超时，死从机每台吃满 800ms，N 台就是 N×800ms。拆成「等首字节 150ms + 帧间静默 50ms + 绝对兜底 300ms」后，死从机单台从 830ms 降到 ~160ms；配合死从机跳过（连续 5 次失败后每 10 轮才探测），多挂从机不再拖慢整轮轮询。

---

**一句话总结**：`超时` 和 `轮询周期` 是两套东西——超时是「到点就放弃 / 判失败」的上限，轮询周期是「到点就跑下一轮」的节拍；剩下的是固定延时、硬件时序、时基和次数上限。
